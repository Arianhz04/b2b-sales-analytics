# Notebook guide

Run notebooks in numeric order from the repository root. Keep the source CSVs in `data/raw/` unchanged. Notebook 02 creates `data/processed/modeling_dataset.csv`; notebook 03 creates `reports/ml_evaluation_report.md`. A model is not recommended unless it passes the training-only screening rule. See the root README and `docs/ml_methodology.md` for scope and limitations.
